# Teacher-Mi 智能教学助手

基于 AI 的日常办公辅助 Web 应用，提供学生管理、作业批改、课程排课、AI 个性化练习生成、学习周报等功能，分为教师端和学生端。

## 功能总览

| 端 | 功能 | 说明 |
|---|---|---|
| 教师端 | 学生管理 | 创建 / 编辑 / 删除学生账号，重置密码，按姓名、学号、班级搜索 |
| 教师端 | 作业管理 | 布置作业（标题、要求、截止时间），**可单独下发或批量下发给多个学生**；可上传作业附件，也可由 AI 根据学生反馈综合生成作业要求；同一页面可发起 **AI 个性化练习** |
| 教师端 | 批改与反馈 | 支持按作业或按学生两种方式查看提交；填写分数与评语，支持 AI 辅助批改、在线文字批注、上传批注文件，**图片 / PDF 附件可在线涂鸦圈画批改**；批改后可「退回重交」让学生再次提交（历史提交保留），确认无误后点「已完成」结束流程 |
| 教师端 | 排课系统 | 为学生安排课程（按小时选时段），查看日/周课表，录入课程反馈，反馈支持 **AI 润色扩写**（写要点 → 生成完整文案 → 编辑确认后保存）；学生可回复反馈 |
| 教师端 | 学习周报 | 选学生与周，AI 自动汇集该生**本周的作业批改与课堂反馈**生成学习周报草稿；教师编辑确认后**发送给学生**，学生端「我的消息」中查看 |
| 教师端 | AI 设置 | 配置任意 OpenAI 兼容服务（地址、API Key、模型名），支持连通性测试；可设置个性化练习最大并发任务数 |
| 教师端 | 修改密码 | 顶栏入口，验证原密码后设置新密码 |
| 学生端 | 我的作业 | 查看作业列表（含老师下发的个性化练习），提交文字内容与附件（≤ 20MB）；被退回后可**重新提交**（每次只保留最新一份，历史提交由教师端留存）；每条作业下查看老师反馈并可查看批注 |
| 学生端 | 我的课表 | 查看老师排的课程及老师的课程反馈，可回复 |
| 学生端 | 我的消息 | 查阅老师发送的**学习周报**，老师发送后实时推送出现 |
| 学生端 | 修改密码 | 顶栏入口，验证原密码后设置新密码 |
| 通用 | 实时刷新 | 师生交互后相关页面**自动刷新**（SSE 推送），无需手动刷新网页 |
| 通用 | 传输安全 | 登录密码经 **RSA 加密**后传输，服务端校验（防重放），抓包不可见明文 |
| 通用 | 手机适配 | 学生端页面针对手机浏览器做了响应式适配，手机可直接访问使用 |

## 技术栈

- 后端：Python 3.10+ / FastAPI / SQLAlchemy / SQLite / ReportLab（PDF 生成）/ asyncio 任务队列
- 前端：Vue 3 / Element Plus / Pinia / Vue Router / Vite / pdfjs-dist（涂鸦批改 PDF 渲染）/ jsencrypt（登录加密）
- AI：OpenAI 兼容 Chat Completions 接口

## 快速开始

### 方式一：Docker 部署（推荐，开箱即用）

镜像由 GitHub Actions 自动构建（amd64 + arm64 双架构），服务器只需安装 Docker：

```bash
mkdir teacher-mi && cd teacher-mi
# 准备 docker-compose.yml（见仓库文件，把 build: . 删掉并改 image 为 ghcr.io/<用户名>/teacher-mi:latest）
docker compose up -d
```

访问 `http://服务器IP:8000` 即可，数据库与附件自动持久化到 `./docker-data/`。

**更新版本**（数据不丢失）：

```bash
# 建议先备份数据库
cp docker-data/db/teacher_mi.db docker-data/db/backup_$(date +%Y%m%d).db
docker compose pull && docker compose up -d
```

镜像构建：推送到 `main`/`master` 分支或在 GitHub 仓库 Actions 页面手动触发，产物发布到 ghcr.io。

### 方式二：本地开发

环境要求：Python 3.10+、Node.js 18+。

```bash
# 启动后端
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 启动前端（另开终端）
cd frontend
npm install
npm run dev
```

访问 <http://localhost:5173/>，开发模式下 `/api` 请求自动代理到后端 8000 端口。

## 使用指南

### 第一步：配置 AI 模型（教师端）

进入「AI 设置」页面，填写三项配置并打开启用开关：

| 配置项 | 说明 | 示例 |
|---|---|---|
| 接口地址 | 填到 `/v1` 这一层，不要带 `/chat/completions`（系统自动拼接） | `https://api.deepseek.com/v1` |
| API Key | 服务商颁发的密钥；已保存后留空表示沿用原 Key | `sk-xxxxxxxx` |
| 模型名称 | 该服务下的模型 ID | `deepseek-chat` |

常见服务商配置示例：

| 服务商 | 接口地址 | 模型名示例 |
|---|---|---|
| OpenAI 官方 | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

保存后点击「测试连通性」，提示成功即可使用 AI 功能。

### 第二步：创建学生账号（教师端）

进入「学生管理」→「新增学生」，填写登录账号、初始密码、姓名、学号、班级，保存后将账号密码分发给学生。

### 第三步：排课（教师端）

进入「排课」，为学生安排课程：选择学生、日期与时段（按小时），保存后进入日/周课表；每节课可录入学习反馈，学生端可在「我的课表」查看课程与反馈并回复。

### 第四步：布置作业（教师端）

进入「作业管理」→「布置新作业」，顶部可选两种作业方式：

**手动布置**：填写标题、要求，可设置截止时间：

- **下发对象**：可选择下发给某个学生，或勾选多个学生批量下发
- **作业要求来源**：可手动输入；也可点击「AI 综合反馈生成」让 AI 根据学生的日常反馈综合生成；还可上传作业附件
- 发布后学生端「我的作业」自动出现（实时刷新，无需手动刷新页面）

**AI 个性化练习**：勾选学生（每人生成一份独立练习），并可自选**关注点来源**：

- 可单选/多选该生的**课程反馈**（某节或多节课的教师反馈与学生回复）、**作业批改记录**（某次或多次提交的批改），或两者组合；某类不选则默认使用该生全部记录
- 提交后后台异步生成（每人一个独立任务，右下角浮窗显示进度）
- 生成完成后作业管理页顶部出现「**AI 练习待确认**」区块：教师可**编辑**（修改标题/内容后自动重建 PDF）→「**确认下发**」转为作业条目发给该学生，或「**驳回**」不下发

### 第五步：学生提交作业（学生端）

学生登录后进入「我的作业」→「提交作业」，填写文字内容并可上传附件（≤ 20MB）。被老师退回的作业可**重新提交**，最新一次提交供老师批改。

> 学生端已适配手机浏览器：手机上访问 `http://<教师电脑IP>:5173/`（开发模式）或服务器地址（Docker 部署）即可使用（需与服务器在同一局域网）。作业列表在手机上以卡片展示，上传附件时可直接选择手机相册照片。

### 第六步：批改与反馈（教师端）

1. 进入「批改与反馈」，两种查看方式：**选择作业**查看该作业全部提交，或**选择学生**查看该学生所有作业提交。
2. 点击「批改」，可查看提交内容并下载附件，填写分数、评语与在线批注，还可上传批注文件；点击「AI 辅助批改」可让 AI 生成分数和评语建议并自动填入，教师可修改后保存。
3. 图片（png / jpg / gif / bmp / webp）或 PDF 附件的提交，点击「**涂鸦批改**」可在线圈画：支持画笔 / 橡皮、颜色、粗细、撤销、清空；PDF 逐页渲染可翻页标注。保存后自动生成批注图片存入反馈。
4. 批改不代表作业无误：如需学生改进，点击「**退回重交**」，学生可重新提交（老提交与反馈保留为历史）；确认全部完成后点击「**已完成**」结束流程，已完成的作业不能再提交或退回。
5. 点击「保存反馈」后学生端对应作业条目下即可查看分数、评语，并可**在线查看**老师批注的图片或下载批注文件。

### 第七步：课程反馈润色与学习周报（教师端）

**课程反馈 AI 润色**：排课页点课程卡片 → 录入新反馈处先写几句要点 → 点「**AI 润色扩写**」→ AI 生成通顺完整的反馈文案并回填编辑框 → 检查修改后「保存反馈」。

**学习周报**：

1. 进入「**学习周报**」，选择日期（自动定位所在周）与学生，点击「AI 生成周报草稿」。
2. AI 自动汇集该生**本周**的出勤课程、每节课教师反馈与学生回复、作业提交与批改情况，生成包含学习内容概览、作业完成情况、课堂表现与进步亮点、不足与下周建议的周报。
3. 同周重复生成会覆盖原草稿；在列表中「编辑」修改标题与内容，确认后「**发送给学生**」。
4. 已发送的周报不可编辑；学生端「**我的消息**」实时收到新周报。

> 周报与个性化练习均需 AI 已配置并启用。

## 常见问题

**Q：调用 AI 功能提示「AI 模型未配置或未启用」？**
进入「AI 设置」完成配置并启用，点击「测试连通性」确认可用。

**Q：AI 批改或练习生成返回 502？**
检查接口地址是否正确（是否多了或少了一段路径）、API Key 是否有效、模型名是否拼写正确、账户是否有余额。

**Q：前端页面打不开或接口 401？**
确认两个服务都在运行：后端 8000、前端 5173。401 表示登录过期，重新登录即可。

**Q：如何修改默认教师密码？**
登录后点击顶栏「修改密码」，验证原密码后设置新密码（学生账号同理）。学生忘记密码时，教师可在「学生管理」中重置。

**Q：个性化练习任务显示「生成中」但一直不动？**
后台任务每秒调度一次，长任务受 AI 接口响应速度影响；服务重启后中断的任务会自动重新排队，不会丢失。可在任务浮窗中查看状态与失败原因。

**Q：手机访问不了学生端？**
确认手机与服务器在同一局域网，用 `http://<服务器IP>:5173/`（开发模式）或 `http://<服务器IP>:8000/`（Docker）访问，不是 localhost。若仍不通，检查防火墙是否放行对应端口。

**Q：如何扩展新功能？**
后端每个业务一个 router 文件：`models.py` 加表 → `routers/` 加路由并在 `main.py` 注册 → 前端 `views/` 加页面并在 `router/index.js` 与布局菜单注册。

## 安全提示

- 生产部署请更换 [config.py](backend/app/config.py) 中的 `SECRET_KEY`，勿用默认值。
- 登录密码虽已 RSA 加密传输，但整体仍是 HTTP；公网部署建议在前面加 Nginx 反向代理并启用 HTTPS。
- 前端使用哈希路由与本地存储令牌，适合个人或班级内网使用。
