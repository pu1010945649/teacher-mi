# Teacher-Mi 智能教学助手

基于 AI 的日常办公辅助 Web 应用，提供学生管理、作业批改、学生反馈归档与 AI 个性化练习生成功能，分为教师端和学生端。

## 功能总览

| 端 | 功能 | 说明 |
|---|---|---|
| 教师端 | 学生管理 | 创建 / 编辑 / 删除学生账号，重置密码，按姓名、学号、班级搜索 |
| 教师端 | 作业管理 | 布置作业（标题、要求、截止时间），**可单独下发或批量下发给多个学生**；可上传作业附件，也可由 AI 根据学生反馈综合生成作业要求 |
| 教师端 | 批改与反馈 | 支持按作业 + 学生筛选提交；填写分数与评语，支持 AI 辅助批改、在线文字批注、上传批注文件，**图片 / PDF 附件可在线涂鸦圈画批改** |
| 教师端 | 个性化练习 | AI 根据学生历史得分与评语自动生成针对性练习，可下载 PDF |
| 教师端 | AI 设置 | 配置任意 OpenAI 兼容服务（地址、API Key、模型名），支持连通性测试 |
| 教师端 | 修改密码 | 顶栏入口，验证原密码后设置新密码 |
| 学生端 | 我的作业 | 查看作业列表，提交文字内容与附件（≤ 20MB），已批改前可重新提交 |
| 学生端 | 我的反馈 | 查看历史批改反馈（分数、评语、批注、时间线归档），**老师批注图片可在线查看** |
| 学生端 | 我的练习 | 查看并下载教师为其生成的个性化练习 PDF |
| 学生端 | 修改密码 | 顶栏入口，验证原密码后设置新密码 |
| 通用 | 手机适配 | 学生端页面针对手机浏览器做了响应式适配，手机可直接访问使用 |

## 技术栈

- 后端：Python 3.10+ / FastAPI / SQLAlchemy / SQLite / ReportLab（PDF 生成）
- 前端：Vue 3 / Element Plus / Pinia / Vue Router / Vite / pdfjs-dist（涂鸦批改时 PDF 渲染）
- AI：OpenAI 兼容 Chat Completions 接口

## 快速开始

### 1. 环境要求

- Python 3.10 及以上
- Node.js 18 及以上

### 2. 启动后端

```bash
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动会自动创建 SQLite 数据库文件 `backend/teacher_mi.db`，并初始化默认教师账号。

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
```

启动后访问 <http://localhost:5173/>。开发模式下前端已配置代理，`/api` 请求自动转发到后端 8000 端口。

### 4. 登录

| 角色 | 账号 | 密码 | 说明 |
|---|---|---|---|
| 教师 | `admin` | `admin123` | 首次启动自动创建，建议尽快修改密码 |
| 学生 | 由教师创建 | 由教师设置 | 在教师端「学生管理」中创建后分发 |

## 使用指南

### 第一步：配置 AI 模型（教师端）

进入「AI 设置」页面，填写三项配置并打开启用开关：

| 配置项 | 说明 | 示例 |
|---|---|---|
| 接口地址 | 填到 `/v1` 这一层，不要带 `/chat/completions`（系统自动拼接） | `https://api.deepseek.com/v1` |
| API Key | 服务商颁发的密钥；已保存后留空表示沿用原 Key | `sk-xxxxxxxx` |
| 模型名称 | 该服务下的模型 ID | `deepseek-chat` |

常见服务商配置示例：

| 服务商 | 接口地址 | 模型名示例 |
|---|---|---|
| OpenAI 官方 | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

保存后点击「测试连通性」，提示成功即可使用 AI 功能。

### 第二步：创建学生账号（教师端）

进入「学生管理」→「新增学生」，填写登录账号、初始密码、姓名、学号、班级，保存后将账号密码分发给学生。

### 第三步：布置作业（教师端）

进入「作业管理」→「布置新作业」，填写标题、要求，可设置截止时间：

- **下发对象**：可选择下发给某个学生，或勾选多个学生批量下发
- **作业要求来源**：可手动输入；也可点击「AI 生成」让 AI 根据学生的日常反馈意见综合生成；还可上传作业附件
- 发布后学生端即可看到

### 第四步：学生提交作业（学生端）

学生登录后进入「我的作业」→「提交作业」，填写文字内容并可上传附件（≤ 20MB）。已批改的作业不可重新提交。

> 学生端已适配手机浏览器：手机上访问 `http://<教师电脑IP>:5173/` 即可使用（需与教师电脑在同一局域网）。作业列表在手机上以卡片展示，上传附件时可直接选择手机相册照片。

### 第五步：批改与反馈（教师端）

1. 进入「批改与反馈」，**选择作业**（可再按学生筛选），列表展示对应提交。
2. 点击「批改」，可查看提交内容并下载附件，填写分数、评语与在线批注，还可上传批注文件；点击「AI 辅助批改」可让 AI 生成分数和评语建议并自动填入，教师可修改后保存。
3. 图片（png / jpg / gif / bmp / webp）或 PDF 附件的提交，点击「**涂鸦批改**」可在线圈画：支持画笔 / 橡皮、颜色、粗细、撤销、清空；PDF 逐页渲染可翻页标注。保存后自动生成批注图片存入反馈。
4. 点击「保存反馈」，该提交标记为「已批改」，学生端「我的反馈」中即可查看分数、评语，并可**在线查看**老师批注的图片或下载批注文件。

### 第六步：生成个性化练习（教师端，可选）

1. 进入「个性化练习」，选择学生，可附加关注点（如「口算能力」「单位换算」）。
2. 点击「AI 生成个性化练习」，系统汇总该学生的全部作业得分、教师评语与提交摘要，由 AI 生成 6–10 道针对性题目。
3. 生成后自动产出 PDF（含姓名 / 班级 / 日期填写栏），可预览或下载。
4. 学生在学生端「我的练习」中查看并下载。

> 前提：该学生需有至少一条学习记录（作业提交），且 AI 已配置并启用。

## 数据存储

- 数据库：`backend/teacher_mi.db`（SQLite 单文件，备份即复制此文件）
- 附件与 PDF：`backend/uploads/`

## 常见问题

**Q：调用 AI 功能提示「AI 模型未配置或未启用」？**
进入「AI 设置」完成配置并启用，点击「测试连通性」确认可用。

**Q：AI 批改或练习生成返回 502？**
检查接口地址是否正确（是否多了或少了一段路径）、API Key 是否有效、模型名是否拼写正确、账户是否有余额。

**Q：前端页面打不开或接口 401？**
确认两个服务都在运行：后端 8000、前端 5173。401 表示登录过期，重新登录即可。

**Q：如何修改默认教师密码？**
登录后点击顶栏「修改密码」，验证原密码后设置新密码（学生账号同理）。学生忘记密码时，教师可在「学生管理」中重置。

**Q：手机访问不了学生端？**
确认手机与教师电脑在同一局域网，且用 `http://<教师电脑IP>:5173/` 访问（不是 localhost）。若仍不通，检查防火墙是否放行 5173 端口。

**Q：如何扩展新功能？**
后端每个业务一个 router 文件：`models.py` 加表 → `routers/` 加路由并在 `main.py` 注册 → 前端 `views/` 加页面并在 `router/index.js` 与布局菜单注册。

## 安全提示

- 生产部署请更换 [config.py](backend/app/config.py) 中的 `SECRET_KEY`，勿用默认值。
- 前端当前使用哈希路由与本地存储令牌，适合个人或班级内网使用；公网部署建议加 HTTPS 与反向代理。
